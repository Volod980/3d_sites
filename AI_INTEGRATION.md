# 🤖 Інтеграція AI асистента

## Що було додано

В проект інтегровано **Google Gemini AI** для покращення досвіду користувача при плануванні туристичних маршрутів.

## Можливості AI асистента

### 1. 💬 Інтелектуальний чат
- Відповідає на питання про визначні місця
- Надає історичну та культурну інформацію
- Допомагає з плануванням маршруту
- Розуміє контекст розмови

**Приклади запитів:**
- "Розкажи про історію Софійського собору"
- "Що цікавого в Андріївському узвозі?"
- "Скільки часу потрібно на відвідування музею?"

### 2. ✨ Персоналізовані рекомендації
AI аналізує ваш запит і автоматично обирає найбільш підходящі місця з доступного списку.

**Приклади запитів:**
- "Романтична прогулянка на вечір"
- "Історичні місця Київської Русі"
- "Місця для сімейного відпочинку"
- "Православні святині"
- "Парки та природа"

### 3. 📝 Опис маршруту
AI створює привабливі описи побудованих маршрутів, що допомагає краще зрозуміти, що вас чекає.

## Як використовувати

### Крок 1: Отримання API ключа

1. Перейдіть на https://aistudio.google.com/apikey
2. Увійдіть через Google акаунт
3. Натисніть "Create API Key"
4. Скопіюйте згенерований ключ

### Крок 2: Налаштування

1. Відкрийте файл `/backend/.env`
2. Знайдіть рядок `GEMINI_API_KEY=`
3. Вставте ваш ключ:
   ```
   GEMINI_API_KEY=your_actual_key_here
   ```
4. Збережіть файл
5. Перезапустіть backend сервер:
   ```bash
   cd backend
   npm run dev
   ```

### Крок 3: Використання

1. Відкрийте сайт: http://localhost:5173
2. Знайдіть місто (наприклад, "Київ")
3. Натисніть на кнопку **"🤖 AI Асистент"**
4. Виберіть дію:
   - **💬 Спитати** - задати питання AI
   - **✨ Рекомендації** - отримати рекомендації місць

## Технічна реалізація

### Backend (Node.js + Express)

**Нові файли:**
- `/backend/src/services/aiService.ts` - Сервіс для роботи з Gemini API
- `/backend/src/controllers/aiController.ts` - Контролери для AI endpoints
- `/backend/src/routes/aiRoutes.ts` - Маршрути AI API
- `/backend/src/data/mockPlaces.ts` - Mock дані для Києва (15 місць)

**Endpoints:**
- `GET /api/ai/status` - Перевірка доступності AI
- `POST /api/ai/chat` - Чат з AI асистентом
- `POST /api/ai/recommendations` - Отримання рекомендацій місць
- `POST /api/ai/route-description` - Генерація опису маршруту

### Frontend (React + TypeScript)

**Нові файли:**
- `/frontend/src/components/AIAssistant.tsx` - Компонент AI чату
- Оновлено `/frontend/src/services/api.ts` - Додано методи для AI API
- Оновлено `/frontend/src/components/Sidebar.tsx` - Інтеграція AI асистента
- Оновлено `/frontend/src/styles/App.css` - Стилі для AI компонента

## Безпека API ключа

⚠️ **ВАЖЛИВО:**
- Ніколи не комітьте файл `.env` з реальним API ключем в Git
- API ключ зберігається тільки на backend сервері
- Frontend не має прямого доступу до API ключа
- Всі запити до Gemini проходять через backend

## Troubleshooting

### AI асистент недоступний
**Проблема:** Бачите повідомлення "AI асистент недоступний"

**Рішення:**
1. Перевірте, що GEMINI_API_KEY додано в `/backend/.env`
2. Перезапустіть backend сервер
3. Перевірте, що ключ валідний на https://aistudio.google.com

### Помилка "API key not valid"
**Проблема:** API ключ не працює

**Рішення:**
1. Перевірте, що ключ скопійовано повністю без пробілів
2. Створіть новий ключ на https://aistudio.google.com/apikey
3. Перевірте, що не перевищено ліміт безкоштовного використання

### AI не відповідає
**Проблема:** Запити зависають або не повертають відповіді

**Рішення:**
1. Перевірте інтернет з'єднання backend сервера
2. Перевірте логи backend: повинні бути записи про AI запити
3. Спробуйте простіший запит

## Обмеження безкоштовного плану

Google Gemini має такі ліміти для безкоштовного використання:
- **15 запитів на хвилину**
- **1500 запитів на день**
- **1 мільйон токенів на хвилину**

Цього більш ніж достатньо для персонального використання та тестування!
