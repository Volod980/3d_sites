# 🗺️ Конструктор туристичних маршрутів

Веб-додаток для побудови оптимальних туристичних маршрутів по Україні. Знаходьте пам'ятки, музеї, парки, історичні місця та інші цікаві локації, обирайте потрібні та отримуйте найкоротший маршрут для їх відвідування.

## 📋 Особливості

- **Пошук туристичних місць** по містах України
- **Різноманітні категорії**: історичні пам'ятки, музеї, парки, замки, релігійні споруди, природні пам'ятки тощо
- **Інтерактивна карта** з відображенням всіх знайдених місць
- **Вибір місць** які ви хочете відвідити
- **Оптимізація маршруту** за відстанню (алгоритм TSP)
- **Візуалізація маршруту** на карті з відображенням відстаней
- **Детальна інформація** про кожне місце (адреса, опис, веб-сайт)

## 🛠 Технології

### Backend
- **Node.js** + **Express** + **TypeScript**
- **OpenStreetMap Overpass API** - для отримання даних про туристичні місця
- **Алгоритм оптимізації** - Nearest Neighbor + 2-opt для вирішення задачі комівояжера (TSP)

### Frontend
- **React** + **TypeScript** + **Vite**
- **Leaflet** + **React-Leaflet** - для відображення інтерактивної карти
- **Axios** - для HTTP запитів

## 🚀 Швидкий старт

### Передумови

Переконайтесь, що у вас встановлено:
- **Node.js** (версія 18 або вище)
- **npm** або **yarn**

### 1. Клонування репозиторію

```bash
git clone <repository-url>
cd 3d_sites
```

### 2. Встановлення залежностей

#### Backend
```bash
cd backend
npm install
```

#### Frontend
```bash
cd ../frontend
npm install
```

### 3. Налаштування змінних оточення

#### Backend
```bash
cd backend
cp .env.example .env
```

Файл `.env` вже налаштований за замовчуванням:
```
PORT=3000
NODE_ENV=development
OVERPASS_API_URL=https://overpass-api.de/api/interpreter
```

#### Frontend (опціонально)
```bash
cd ../frontend
cp .env.example .env
```

### 4. Запуск додатку

#### Варіант 1: Запуск в режимі розробки

**Backend** (в одному терміналі):
```bash
cd backend
npm run dev
```
Backend запуститься на http://localhost:3000

**Frontend** (в іншому терміналі):
```bash
cd frontend
npm run dev
```
Frontend запуститься на http://localhost:5173

#### Варіант 2: Запуск продакшн збірки

**Backend:**
```bash
cd backend
npm run build
npm start
```

**Frontend:**
```bash
cd frontend
npm run build
npm run preview
```

### 5. Відкрийте додаток

Відкрийте браузер і перейдіть на:
```
http://localhost:5173
```

## 📖 Використання

1. **Введіть назву міста** в поле пошуку (наприклад: Київ, Львів, Одеса, Харків)
2. **Натисніть "Знайти пам'ятки"** - на карті з'являться туристичні місця
3. **Оберіть місця** які хочете відвідати (клікайте на картки місць або маркери на карті)
4. **Натисніть "Побудувати маршрут"** (потрібно мінімум 2 місця)
5. **Перегляньте оптимізований маршрут** на карті та загальну відстань

## 🌍 API Endpoints

### Пошук місць
```
GET /api/places/search?city=Київ&limit=100
```

### Отримання місць по місту
```
GET /api/places/city/:cityName
```

### Деталі місця
```
GET /api/places/:id
```

### Побудова маршруту
```
POST /api/places/route
Body: {
  "placeIds": ["node/123", "way/456"],
  "startPoint": { "latitude": 50.45, "longitude": 30.52 }
}
```

## 🔧 Алгоритм оптимізації маршруту

Використовується комбінація двох алгоритмів для вирішення задачі комівояжера (TSP):

1. **Nearest Neighbor** - швидкий жадібний алгоритм для початкового маршруту
2. **2-opt** - локальна оптимізація для покращення маршруту

Це дозволяє знайти близький до оптимального маршрут за розумний час навіть для великої кількості точок.

## 📝 Джерела даних

Всі дані про туристичні місця отримуються з **OpenStreetMap** через **Overpass API**.

Категорії місць:
- Історичні пам'ятки (замки, археологічні пам'ятки, руїни)
- Музеї та галереї
- Релігійні споруди (церкви, собори, монастирі)
- Природні пам'ятки (національні парки, водоспади, печери, гори)
- Парки та заповідники
- Оглядові майданчики
- Архітектурні споруди
- Культурні місця
