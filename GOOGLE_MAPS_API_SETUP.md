# 🗺️ Як отримати Google Maps API ключ

Детальна покрокова інструкція для отримання безкоштовного API ключа Google Maps Places API.

---

## Крок 1: Перейдіть в Google Cloud Console

Відкрийте у браузері: **https://console.cloud.google.com/**

- Увійдіть через ваш Google акаунт (Gmail)
- Якщо це ваш перший візит - прийміть умови використання

---

## Крок 2: Створіть новий проект

1. Зверху зліва натисніть на поточний проект (або "Select a project")
2. У вікні що відкрилося натисніть **"NEW PROJECT"** (правий верхній кут)
3. Введіть назву проекту, наприклад: `tour-builder-ukraine`
4. Натисніть **"CREATE"**
5. Зачекайте ~30 секунд поки проект створюється
6. Оберіть щойно створений проект у списку

---

## Крок 3: Увімкніть Places API (New)

### Варіант А - Через пошук:
1. Вгорі є поле пошуку - введіть: `Places API`
2. Виберіть **"Places API (New)"** (не стару версію!)
3. Натисніть синю кнопку **"ENABLE"**

### Варіант Б - Через меню:
1. Відкрийте бічне меню (☰) зліва
2. Перейдіть: **APIs & Services → Library**
3. У пошуку введіть: `Places`
4. Оберіть **"Places API (New)"**
5. Натисніть **"ENABLE"**

⚠️ **Важливо:** Використовуйте **Places API (New)**, а не застарілу версію!

---

## Крок 4: Налаштуйте білінг (Обов'язково!)

Google вимагає додати платіжну інформацію, але **перші $200/місяць безкоштовні!**

1. Відкрийте меню → **Billing**
2. Натисніть **"Link a billing account"**
3. Якщо у вас немає білінг акаунту - створіть новий:
   - Натисніть **"CREATE BILLING ACCOUNT"**
   - Виберіть країну
   - Прийміть умови
   - Введіть дані картки
   - Підтвердіть
4. Прив'яжіть білінг акаунт до вашого проекту

### 💰 Безкоштовний ліміт:
- **$200 кредитів щомісяця** (оновлюється автоматично)
- **Places API Nearby Search:** ~28,000 запитів безкоштовно
- **Places API Text Search:** ~10,000 запитів безкоштовно
- **Places API Details:** ~28,000 запитів безкоштовно

Для персонального проекту цього **більш ніж достатньо!** Гроші з картки не знімуться, доки ви не перевищите ліміт.

---

## Крок 5: Створіть API ключ

1. Відкрийте меню → **APIs & Services → Credentials**
2. Натисніть **"+ CREATE CREDENTIALS"** вгорі
3. Виберіть **"API key"**
4. Ключ буде створено автоматично - **скопіюйте його!**

Ви побачите щось схоже на:
```
AIzaSyDXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

---

## Крок 6: Обмежте ключ (Рекомендовано)

Для безпеки обмежте що може робити ваш API ключ:

1. Натисніть на назву щойно створеного ключа
2. У розділі **"API restrictions"**:
   - Виберіть **"Restrict key"**
   - Поставте галочку тільки біля **"Places API (New)"**
3. У розділі **"Application restrictions"** (опціонально):
   - Виберіть **"IP addresses"** якщо запускаєте тільки локально
   - Додайте свою IP адресу
   - Або виберіть **"None"** для тестування
4. Натисніть **"SAVE"** внизу

---

## Крок 7: Додайте ключ в проект

1. Відкрийте файл `/backend/.env` у вашому проекті
2. Додайте рядок:
   ```
   GOOGLE_MAPS_API_KEY=ваш_ключ_тут
   ```

   Наприклад:
   ```
   GOOGLE_MAPS_API_KEY=AIzaSyDXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
   ```

3. Збережіть файл
4. Перезапустіть backend сервер:
   ```bash
   cd backend
   npm run dev
   ```

## Перевірка що все працює

### Тест 1: Перевірте через curl

```bash
curl "https://places.googleapis.com/v1/places:searchText" \
  -H "Content-Type: application/json" \
  -H "X-Goog-Api-Key: ВАШ_КЛЮЧ_ТУТ" \
  -H "X-Goog-FieldMask: places.displayName,places.formattedAddress" \
  -d '{
    "textQuery": "Софійський собор Київ"
  }'
```

Якщо працює - побачите JSON з інформацією про Софійський собор.

### Тест 2: Через ваш додаток

1. Запустіть backend і frontend
2. Введіть "Київ" у пошук
3. Повинні з'явитися реальні місця з Google Maps з рейтингами

## Troubleshooting

### Помилка: "This API key is not authorized to use this service"
**Рішення:**
- Переконайтеся що ви увімкнули **Places API (New)** (не стару версію)
- Почекайте 5-10 хвилин - іноді зміни застосовуються не одразу
- Перевірте що ключ обмежений тільки для Places API

### Помилка: "The request is missing a valid API key"
**Рішення:**
- Перевірте що ключ правильно скопійовано в `.env` файл
- Перезапустіть backend сервер
- Перевірте що немає зайвих пробілів в `.env`

### Помилка: "Project XXX has not enabled the API"
**Рішення:**
- Увімкніть Places API в Google Cloud Console
- Почекайте 2-3 хвилини

### Помилка: "REQUEST_DENIED" або про білінг
**Рішення:**
- Додайте платіжну інформацію (картку) в Billing
- Це обов'язково навіть для безкоштовного використання
- Гроші не знімуться доки не перевищите $200/місяць
