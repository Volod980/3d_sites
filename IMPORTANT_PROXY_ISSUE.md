# ⚠️ ВАЖЛИВО ПРО ЗАПУСК

## Проблема з віддаленим сервером

OpenStreetMap Overpass API **БЛОКУЄТЬСЯ** на віддалених серверах через проксі.

**Помилка:** `403 Forbidden - Access denied`

## ✅ РІШЕННЯ: Запустіть на своєму комп'ютері

Проект **ПРАЦЮВАТИМЕ ТІЛЬКИ** коли ви запустите його **ЛОКАЛЬНО** на своєму комп'ютері!

### Як запустити локально:

1. **Завантажте проект** на свій комп'ютер
2. **Встановіть Node.js** (якщо немає): https://nodejs.org/
3. **Запустіть** за допомогою скриптів:

**Windows:**
```
start.bat
```

**Mac/Linux:**
```
./start.sh
```

4. **Відкрийте** у браузері: http://localhost:5173

### Чому не працює на віддаленому сервері?

- OpenStreetMap блокує запити через проксі
- Nominatim API також може бути заблокований
- Потрібен прямий доступ до інтернету без проксі
